03 / DATA & METHODS

Transparent by design.

OPEN DATA · REPRODUCIBLE METHODS
01

NASA POWER

Daily point data for T2M (air temperature at 2 m), requested for Belagavi, Karnataka from 2015-01-01 through 2025-12-31. The live API response identifies MERRA-2 as the data source; POWER distributes these meteorological reanalysis data in an analysis-ready archive.

Explore the POWER daily API ↗
02

Annual averages

Valid daily values are averaged arithmetically within each calendar year. NASA's missing-data sentinel (−999) is excluded. Coverage is the valid-day count divided by calendar days in that year.

03

Trend & significance

Ordinary least-squares regression estimates the slope of annual means against year. The two-sided Mann–Kendall test uses a tie-corrected variance and continuity-corrected normal approximation; significance threshold α = 0.05.

04

How to read this

Annual means smooth out day-to-day weather and seasonal cycles. The record is short, local-scale results may differ from regional trends, and POWER data is not a substitute for ground-station measurements.
